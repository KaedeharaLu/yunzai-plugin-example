# KimiAI 插件帮助文档
## 简介
KimiAI 是一个基于 Moonshot AI 提供的人工智能助手。该插件由KaedeharaLu开发，包含多种功能，包括设置秘钥、管理对话历史、预设管理等。

## 功能列表
### 1. 基本对话
- **提问**: `#kimi+你的问题` 向Kimi提问。

### 2. 秘钥管理
- **设置秘钥**: `#设置kimi秘钥+你的秘钥` 在私聊中设置你的 API 秘钥。
- **获取秘钥**: 访问 [Moonshot AI 控制台](https://platform.moonshot.cn/console/api-keys) 获取你的 API 秘钥。

### 3. 对话历史管理
- **清空对话历史**: `#km清空对话` 清除自己和Kimi的对话记录。
- **查看对话历史**: `#km对话历史` 查看与Kimi的对话历史。

### 4. 预设管理
- **查看预设列表**: `#km预设查看` 或 `#km预设列表` 查看存储的预设列表。
- **删除预设**: `#km预设删除+编号` 删除对应编号的预设。
- **使用预设**: `#km预设使用+编号` 使用对应编号的预设。
- **添加预设**: `#km预设添加+内容` 将对应预设内容添加到记录。
- **清空预设**: `#km预设清空` 清空自己的预设历史（自动恢复到默认预设）。

### 5. 黑名单
- **拉黑用户**: `#km拉黑+@某人或者QQ号` 拉黑某个用户不得使用KimiAI。
- **取消拉黑**: `#km取消拉黑+@某人或者QQ号` 取消拉黑用户。
- **黑名单查看**: `#km黑名单` 查看黑名单列表。

## 注意事项
- 请确保在使用插件前已经获取了有效的 API 秘钥，并正确设置。
- 所有命令不要加空格。
- 插件中的某些功能只有云崽主人可以调用。
